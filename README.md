
# P-folio | Android Portfolio App

A modern Android portfolio application built using Kotlin and Jetpack Compose, designed to showcase professional profiles, technical skills, projects, and achievements.

## Features

- Modern and responsive user interface
- Personal profile dashboard
- Project showcase
- Skills and achievements
- Contact and social media integration
- Custom portfolio creation
- Multi-step portfolio builder
- Portfolio preview
- Bottom navigation

## Tech Stack

- Kotlin
- Jetpack Compose
- Material Design 3
- Android Studio
- Gradle
- Git & GitHub

## Installation

1. Clone the repository:
   git clone https://github.com/Paraatech/P-folio-.git
2. Open the project in Android Studio.
3. Sync Gradle dependencies.
4. Run on an Android device or emulator.
